# OpenUI Analytics 功能测试用例

> 版本：v1.0 · 适用版本：openui-analytics 0.1.0
> 目的：对项目全部功能进行完整验证，覆盖正常流程、边界条件、异常降级与安全约束。
> 维护方式：新功能上线时同步补充用例；用例编号保持稳定，废弃用例标记「已废弃」而非删除。

## 1. 说明

### 1.1 编号规则

`TC-<模块>-<序号>`，模块缩写见各章节标题，如 `TC-DS-003`。

### 1.2 优先级定义

| 优先级 | 含义 |
| --- | --- |
| P0 | 核心链路/阻塞性问题，不通过则版本不可发布 |
| P1 | 重要功能，影响主要使用体验 |
| P2 | 次要功能、边界与体验优化 |

### 1.3 测试环境基线

| 项 | 要求 |
| --- | --- |
| Node | ≥ 22.13 |
| 包管理 | pnpm 12.x |
| 开发服务 | `pnpm dev`，端口 3006 |
| 本地数据库 | PostgreSQL（`openui_analytics` 等示例库，缺表自动建表写示例数据） |
| 禅道数据源 | 本机已登录 `zentao` CLI（`zentao mcp --read-only`） |
| LLM | OpenAI 兼容接口（页面设置或环境变量 `OPENAI_*` / `LLM_*`） |
| 浏览器 | Chrome 最新版（暗色用例需切换系统外观） |

### 1.4 通用前置条件

除特别说明外，默认：服务已启动于 `http://localhost:3006`；已在「设置」中配置可用的 LLM API Key；`config/datasources.json` 中至少一个 PostgreSQL 源与禅道 CLI 源处于启用状态。

## 23. 执行建议

1. **冒烟先行**：每次回归先跑 TC-ENV + TC-QA 全部 + 各模块 P0 用例（约 60 条）。
